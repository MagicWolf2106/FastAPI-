# 方案 A：个人资讯聚合 + AI 摘要助手（推荐）

做什么 ：爬取感兴趣网站的文章/新闻 → 存入 MySQL → FastAPI 提供浏览、搜索、收藏接口 → AI 自动生成文章摘要和标签

- 练习点最全：爬虫 → 数据库 → API → AI，一条链路全覆盖
- 爬虫目标可以选静态网页（如新闻站、博客），难度可控
- 每个“练习点”都刚好是一个模块，边界清晰

<br />

如你所见，这是一个自动爬取文章显示，然后ai总结文章摘要的简单项目

步骤大概是这样的：

#### 用fastAPI搭建框架，写好接口，接入数据库

到时候爬虫会爬取数据返回json字符串，然后我需要解析json，将得到的信息依次存入数据库

接口是干嘛的？连接前后端，测试时通过不同的接口发出不同指令，比如：

1. 通过删除接口来删除新闻，
2. 通过get接口获取新闻数据（通过爬虫），
3. 获取收藏的新闻
4. 手动添加文章（测试
5. 搜索新闻
